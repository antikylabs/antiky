# Contributing

We welcome contributions to demos, framework, and studios!

We ask that website contributions be limited as that contains antikyLabs main marketing and updates website.

Our contributing rules are simple these days...

## Rules

1. If you have an issue etc, file an issue.
2. If you want to propose a feature or another meaningful product, process, governance, or architectural change, submit an [AIP](docs/aip/README.md) so contributors and Core Contributors can align first.
3. If you want to add a small feature or bug fix (1-3 files, one function, etc.), feel free to open a code PR. Broader changes should start with an AIP.
4. Follow accepted [ADRs](docs/adr/README.md). If an accepted AIP results in an architectural decision, Core Contributors will record that decision as an ADR.
5. Have fun.

## Questions?

If you have questions please join our discord or file an issue!
