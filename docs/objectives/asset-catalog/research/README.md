# Asset-source research corpus

Research date: 2026-08-09

This directory is the evidence base for growing Antiky's CC0-first asset catalog. A source appearing
in a report is not automatically approved. The consolidated catalog and acquisition roadmap apply
the final decision after license, provenance, access, quality, and operational review.

## Interpretation rules

- **CC0** means an authoritative creator or publisher applied the CC0 1.0 legal tool to the work.
- **Public domain** requires authoritative rights evidence appropriate to the work and jurisdiction;
  age, government origin, or a search-engine label is not enough.
- **Permissive but not CC0** sources are useful directions but belong in a separately labeled
  license lane. OFL fonts and MIT code must not be presented as public-domain media.
- **Mixed license** means approval happens per item, never at provider level.
- **Discovery only** means the source can supply leads but is not authoritative license evidence.
- **Metadata ingestion** never implies permission to mirror an archive or hotlink a preview.
- **Copyright clearance** does not clear trademarks, privacy, publicity, cultural restrictions,
  contractual access terms, patents, or export controls.

## Evidence standard

Every approved source needs, at minimum:

1. canonical publisher and item URLs;
2. an authoritative license statement and normalized license identifier;
3. creator/publisher identity and a stable upstream identifier;
4. a documented metadata and preview access method;
5. an automation and rate-limit decision;
6. an explicit archive-mirroring and preview-hosting decision;
7. sample records reviewed for metadata consistency and rights edge cases;
8. a refresh strategy that produces a human-reviewable diff.

Research reports should prefer primary documentation. Aggregators, search results, community posts,
and third-party license summaries can discover a source but cannot approve it.
