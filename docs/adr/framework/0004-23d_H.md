# 0004: Give equal support to 2D, 3D, and 2.3D games

## Status

Accepted

## Context

Antiky's primary games use 2D characters and objects in 3D worlds. These games need complete 2D and
3D features. One data model for only voxels or sprites cannot meet this need.

## Decision

Antiky will give equal framework support to 2D, 3D, and 2.3D games. In Antiky, **2.3D** means 2D
characters and objects in a 3D world.

All three modes will use the shared contracts for world data, commands, assets, physics, and
rendering. When a mode has different needs, it can use a specialized processing path.

## Consequences

- Framework code must not assume that every object is a mesh, sprite, voxel, or rigid body.
- Depth, selection, lighting, physics, animation, and batching must work when a game mixes data
  types.
- Demos for each mode will test shared features and specialized features.
- Emberwyrd is the primary use case. Antiky must also support other games.
