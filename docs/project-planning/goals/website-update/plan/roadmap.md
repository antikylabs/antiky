# Antiky Labs roadmap

**We are building one complete loop: agents can understand and change a game, people can see and
direct the work, and every new capability is proven in something playable.**

> This is a direction roadmap, not a calendar. Each release earns the next through working games.

## v0.1 — Put the foundation in people's hands

**Release a coherent first version of Framework, Studio, agent tools, demos, documentation, and the
website—open, understandable, and ready to try.**

## v0.2 — Make the game part of the conversation

**Click something in a running game, carry its exact identity and context into the coding agent you
already use, and turn human feedback into a safe, inspectable change.**

## v0.3 — Grow the game-making core

**Build input, movement, sprite animation, camera and presentation controls, and the first mini-app
foundation through real game slices in 2D, 3D, and everything in between.**

## v0.4 — Turn Studio into a creator workspace

**Use the mini-app foundation to add focused tools for assets, sprites, flipbooks, and properties,
so Studio changes to fit the work instead of becoming one enormous editor.**

## Beyond — Build a creative library agents can understand

**Grow the CC0 asset catalog alongside shader, project, and skills libraries, giving people and
agents trusted building blocks they can actually find, understand, and reuse.**

## The destination — Ship games that prove the idea

**Use Antiky to create complete, memorable games—and let those games earn the reusable systems,
production tooling, performance evidence, and online capabilities the platform needs next.**
