# Antiky Labs logo assets

These are the canonical monochrome variants of the Antiky Labs identity. Every asset has a transparent
artboard. The SVGs contain self-contained vector geometry, and the name is converted to outlines so
it does not depend on an installed font.

| Composition | White | Black |
| --- | --- | --- |
| Wordmark | [SVG](antiky-labs-wordmark-white.svg) · [PNG](antiky-labs-wordmark-white.png) | [SVG](antiky-labs-wordmark-black.svg) · [PNG](antiky-labs-wordmark-black.png) |
| Wordmark and name | [SVG](antiky-labs-wordmark-and-text-white.svg) · [PNG](antiky-labs-wordmark-and-text-white.png) | [SVG](antiky-labs-wordmark-and-text-black.svg) · [PNG](antiky-labs-wordmark-and-text-black.png) |
| Name only | [SVG](antiky-labs-text-white.svg) · [PNG](antiky-labs-text-white.png) | [SVG](antiky-labs-text-black.svg) · [PNG](antiky-labs-text-black.png) |

The PNGs are rendered at four times the logical logo dimensions: `112×112` for the wordmark,
`496×112` for the wordmark and name, and `520×96` for the name alone.

Use the white variants on dark surfaces and the black variants on light surfaces. Preserve each
asset's aspect ratio and leave the artboard transparent. The company name is set as **Antiky Labs**.
