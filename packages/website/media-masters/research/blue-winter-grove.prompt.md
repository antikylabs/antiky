# Blue Winter Grove publication record

- Generation method: built-in ImageGen with referenced images and precise object edits
- Generated: 2026-08-21
- Original experiment: `research/experiments/asset-generation-contract/docs/dsl-testing`
- Original prompt record: `examples/blue-winter-grove-reference-prompts.md`

The three published frames are the exact `v4` outputs from the DSL experiment. ImageGen received an
environment edit target and the party identity anchor for each final scene edit. The final prompts
required the environment, camera, lighting, palette, and depth of field to remain unchanged while
the same three-character party replaced the earlier placeholder sprites.

The archived party anchor preserves one of those direct visual inputs. The earlier environment edit
targets are not available as separate files in the current experiment bundle. The original prompt
record documents their role and the precise edit constraints.

These files are illustrative references for a proposed authoring contract. They are not captures of
a running Antiky game and must not be presented as product evidence.
