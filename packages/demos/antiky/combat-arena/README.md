# Combat Arena

Combat Arena is a compact Antiky Framework game rendered with custom BroMetal shaders. The
Framework owns its fixed-step combat simulation, entity hierarchy, runtime stores, and bounded hit
history. BroMetal renders the arena, drones, projectiles, dash trails, and impact particles.

```sh
npm run antiky -- dev --project packages/demos/antiky/combat-arena/combat-arena.antiky
```

Move with WASD or the arrow keys. Click or tap the arena to dash through the enemy formation.
