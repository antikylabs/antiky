# Traversal Study

Traversal Study is a looping kinetic platform course powered by Antiky Framework and rendered with
BroMetal. The fixed-step simulation owns running, jumping, moving platforms, hazards, checkpoints,
and particles; Studio can inspect the same platform hierarchy and traversal events seen on screen.

```sh
npm run antiky -- dev --project packages/demos/antiky/traversal-study/traversal-study.antiky
```

The attract loop runs on its own. Use the horizontal controls to steer and click or tap to jump.
