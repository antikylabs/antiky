# Point Light Expo

Prismatic Foundry is an Antiky Framework showcase for three authored, editable point lights and a
custom BroMetal shader. Open `point-light-expo.antiky` in Studio to inspect the light identities,
change their power through the shared development service, and see the render update live.

```sh
npm run antiky -- dev --project packages/demos/antiky/point-light-expo/point-light-expo.antiky
```

`npm run build` compiles the portable module to `dist/antiky.game.js`.
