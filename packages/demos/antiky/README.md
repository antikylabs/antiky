# Antiky Framework demos

These projects use Antiky Framework for simulation or authoring state and BroMetal for rendering.
Open either `.antiky` manifest in Studio to run the same portable game module that ships on the
website.

- **Antiky Town** — a walkable voxel town with Framework-owned lamp authoring.
- **Point Light Expo** — a focused gallery for editable practical lights and custom shaders.
