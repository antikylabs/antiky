# Three.js demos

These projects use Three.js without BroMetal or Antiky Framework. They demonstrate that Studio's
host lifecycle, renderer measurements, development service, and agent connection are renderer
agnostic.

- **Orbital Atlas** — a hierarchical kinetic solar sculpture.
- **Glass Garden** — a luminous physical-material conservatory.

Studio is built for BroMetal, and works with Three.js and other rendering libraries.
