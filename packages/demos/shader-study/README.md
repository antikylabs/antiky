# Shader Study

Shader Study is an Antiky game project. Its default entry draws a typed BroMetal shader on a canvas
that a host supplies.

Open `shader-study.antiky` in Studio, or run:

```sh
npm run antiky -- dev --project packages/demos/shader-study/shader-study.antiky
```

`npm run build` compiles the portable module to `dist/antiky.game.js`.
