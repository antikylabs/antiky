# Pure BroMetal demos

These projects use BroMetal directly and do not depend on Antiky Framework. Each still implements
Studio's small structural game-module contract, so Studio can host it, report renderer measurements,
and expose the development connection to coding agents.

- **Town Study** — a polished walkable voxel scene.
- **Shader Study** — an authored TypeScript shader compiled ahead of time.
- **Solar Forge** — a procedural stellar furnace.
- **Luminous Reef** — a procedural bioluminescent seascape.
