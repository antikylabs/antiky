# Shader Study

Shader Study is a pure BroMetal project. Its default entry draws a typed shader on a canvas that a
host supplies, without an Antiky Framework dependency.

Open `shader-study.antiky` in Studio, or run:

```sh
npm run antiky -- dev --project packages/demos/brometal/shader-study/shader-study.antiky
```

`npm run build` compiles the portable module to `dist/antiky.game.js`.
